# 本轮构建说明（2026-05-24）

## 版本定位

GISQCWorkbench 当前定位为：对外试用版 / 阶段性交付版。

本轮目标不是一次性完成商品化，而是优先补齐客户试用时最容易关注的三件事：

1. 当前到底支持哪些质检规则。
2. 客户能否快速上手跑出报告。
3. 导出的报告是否更像正式交付文档。

## 本轮新增和优化

### 1. 新增支持规则清单

新增文件：

```text
docs\支持规则清单.md
```

内容包括：

- 支持数据类型说明。
- 规则状态说明。
- 默认模板规则数量概览。
- 70 条内置规则明细。
- 35 条默认启用规则。
- 35 条模板预置/未启用规则。
- 每条规则的编码、名称、对象、级别、启用状态、参数、输出提示。

### 2. 新增试用版快速开始

新增文件：

```text
docs\快速开始_试用版.md
```

用于客户试用交付，说明：

- 如何启动软件。
- 如何准备成果目录。
- 如何执行质检。
- 如何导出报告。
- CLI 退出码约定。
- 常见问题和试用版边界。

### 3. 报告模板增强

优化文件：

```text
src\core\ReportExporter.cpp
```

报告新增/增强内容：

- 检查范围。
- 规则清单说明。
- 统计摘要。
- 按规则统计。
- 按图层统计。
- 问题明细空结果提示。
- 检查结论。
- 处理建议。
- Word 兼容报告增加封面和更正式的章节结构。
- Excel 兼容报告增加统计、按规则统计、按图层统计。
- HTML 报告增加规则清单、分组统计和结论模块。

### 4. 打包脚本增强

优化文件：

```text
scripts\build_windows_release.ps1
scripts\package_deliverable.ps1
```

改动：

- Release 交付目录会复制 `docs` 文档目录。
- `交付说明.txt` 增加版本定位、随包文档和报告能力说明。
- 验收建议增加“支持规则清单”检查项。
