# GIS 数据质量检查工作台交付验收清单

## 1. 启动与环境

- 双击 `GISQCWorkbench.exe` 可以打开主界面。
- 交付目录包含 Qt 运行库、`platforms/qwindows.dll`、MSVC 运行库、GDAL/PROJ 运行库与数据目录。
- 主界面采用交付版浅色工作台 UI，左侧导航、顶部标题栏和卡片式内容区与原型方向一致。

## 2. 数据导入

- 可以选择成果目录。
- 可以扫描 Shapefile、GeoPackage、FileGDB 入口。
- 可以显示图层名、类型、要素数、坐标系、读取状态。

## 3. 内部配置

- 规则配置不依赖 Excel。
- 可以启用/停用规则。
- 可以编辑严重级别、问题描述和参数。
- 保存后生成 `data/templates/user_rules.json`，后续执行优先读取。

## 4. 质检执行

- 可以创建任务名称。
- 可以选择成果目录。
- 可以执行内部规则检查。
- 可以生成问题预览并跳转结果中心。
- 每次执行会自动写入 `data/history/task_history.tsv`，首页最近任务卡片可刷新查看。

## 5. 结果与报告

- 结果中心显示总规则数、已通过、警告、错误、通过率。
- 结果中心显示问题清单。
- 可以导出 CSV 问题清单。
- 可以导出 HTML 质检报告。
- 可以导出 Excel 兼容报告。
- 可以导出 Word 兼容报告。
- 可以打开最近一次导出目录。
