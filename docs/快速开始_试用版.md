# GISQCWorkbench 快速开始

本文件用于对外试用交付，目标是让客户在 5 分钟内完成一次 GIS 成果质检并导出报告。

## 1. 启动软件

1. 解压交付包到本地目录，建议路径不要过深，例如：`D:\GISQCWorkbench`。
2. 双击 `GISQCWorkbench.exe`。
3. 如果 Windows 提示未知发布者，选择“更多信息 / 仍要运行”。正式商业发布前建议进行代码签名。

## 2. 准备数据

当前版本重点支持：

- GeoPackage（`.gpkg`）
- Shapefile（`.shp`，同时检查 `.shx/.dbf/.prj` 等配套文件）
- FileGDB（`.gdb`，读取能力取决于随包 GDAL 驱动）

建议成果目录包含：

```text
成果目录/
  空间数据/
  文档资料/
  元数据/
  metadata.xml
  readme.txt
```

## 3. 执行质检

1. 在首页或数据导入页选择成果目录。
2. 确认软件识别到数据源数量。
3. 打开规则配置页，确认默认模板 `GIS数据通用标准化质量检查 V2.0` 已加载；默认模板已启用全部 70 条规则，覆盖目录层级/命名/完整性、文件可读性/命名/扩展名/版本、数据集/数据表分层匹配、表别名/表类型/组织结构、属性字段、坐标系、空间范围、点-点重合、点-线端点/线覆盖、点-面边界/内部、线悬挂点、线伪结点、线连通性伪结点、线-点端点覆盖、线-线覆盖/重叠/相交、线-面边界覆盖、线-面内部包含、面空隙、面重叠、面伪结点、面-点包含、面-点精确一个点、面-线边界覆盖、面-面覆盖/相互覆盖/重叠/边界覆盖等核心规则。
4. 进入执行质检页，点击开始执行。
5. 质检完成后查看统计摘要和问题清单。

## 4. 导出报告

结果页支持导出：

- CSV 问题清单
- HTML 报告
- Excel 兼容报告（`.xls` HTML 格式）
- Word 兼容报告（`.doc` HTML 格式）

报告已包含：

- 项目/任务信息
- 检查范围
- 规则清单说明
- 统计摘要
- 按规则统计
- 按图层统计
- 问题明细
- 检查结论和处理建议

## 5. 命令行快速验证

也可以用 CLI 做自动化验证：

```bash
GISQCWorkbenchCLI.exe <成果目录> <输出CSV路径>
```

退出码约定：

- `0`：执行成功，未发现问题。
- `2`：执行成功，发现质检问题。
- `1`：执行失败，例如输入目录不存在或输出文件无法写入。

## 6. 规则清单

交付包内提供：

```text
docs\支持规则清单.md
```

用于说明当前版本支持哪些规则、哪些默认启用、哪些是模板预置但未启用。

## 7. 常见问题

### Q1：为什么报告里有“模板预置/未启用”的规则？

这些规则是为行业模板和项目模板预留的配置项，默认不参与执行。正式项目可根据客户规范启用并配置参数。

### Q2：为什么 FileGDB 读取结果和客户机器有关？

FileGDB 依赖 GDAL/OGR 驱动能力。当前交付包已随包带 GDAL/PROJ 运行数据，但不同 FileGDB 数据结构仍建议先做样例验证。

### Q3：客户反馈“跑不出来”时怎么办？

请收集：

1. 软件版本和交付包名称。
2. 成果目录结构截图。
3. 导出的 CSV/HTML/Word/Excel 报告。
4. 命令行运行输出或错误提示。
5. 如涉及敏感数据，可提供脱敏样例包复现。
