# 授权注册说明

本软件已接入轻量离线授权系统，用于试用版/商业交付时控制机器绑定、有效期和运行次数。

## 授权机制

主程序启动时会校验 `license.dat`：

- 产品名：`GISQCWorkbench`
- 机器码：绑定当前电脑
- 有效期：超过日期后拒绝运行
- 最大运行次数：每次启动主程序、CLI 或预览版都会递增
- 签名：授权文件被手工篡改后校验失败

授权状态文件保存于当前用户本地目录，用于记录已运行次数。

## 获取机器码

在客户电脑上运行：

```bat
LicenseGenerator.exe --machine-code
```

也可以直接运行未授权的 `GISQCWorkbenchCLI.exe` 查看提示中的机器码。

## 生成授权文件

在交付方电脑或受控环境中运行：

```bat
LicenseGenerator.exe --generate <机器码> <有效期YYYY-MM-DD> <最大运行次数> license.dat
```

示例：

```bat
LicenseGenerator.exe --generate ABCD-1234-EF56-7890 2026-12-31 100 license.dat
```

`maxRuns` 设置为 `0` 表示不限运行次数。

## 安装授权文件

将生成的 `license.dat` 放到程序运行目录，或放到提示中的默认授权路径。

推荐随程序放置：

```text
GISQCWorkbench-latest\license.dat
GISQCWorkbench-latest\GISQCWorkbench.exe
GISQCWorkbench-latest\GISQCWorkbenchCLI.exe
```

## 未授权表现

- GUI：弹出“授权校验失败”，展示机器码和授权文件位置。
- CLI：返回退出码 `3`，输出机器码和授权文件位置。

## 注意

这是离线轻量授权方案，可防止普通复制传播和简单篡改。若需要更高强度，可后续接入代码混淆、在线激活、硬件指纹多因子、签名证书和反调试策略。
