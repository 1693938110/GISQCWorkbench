# GISQCWorkbench 支持规则清单

本文档面向试用客户和项目验收人员，说明当前默认规则模板中已内置的质检规则、启用状态和主要参数。

## 支持数据类型

- GeoPackage（`.gpkg`）：已作为重点测试数据源。
- Shapefile（`.shp`）：支持入口识别和配套文件完整性检查。
- FileGDB（`.gdb`）：支持目录型数据源入口识别；具体图层读取能力取决于随包 GDAL 驱动。
- 其他 GDAL/OGR 可读矢量数据源：可随 GDAL 能力扩展，建议在正式项目中先做样例验证。

## 规则状态说明

- **已启用**：默认模板会参与质检执行。
- **模板预置/未启用**：规则已在模板中占位，适合作为行业模板或项目模板继续配置；默认不参与执行。
- 严重级别包括：`error`（错误）、`warning`（警告）。

## 规则数量概览

- 默认模板：GIS数据通用标准化质量检查 V2.0`GIS_QC_STANDARD_V2`
- 规则总数：70

- 属性专题：15 条
- 空间专题：43 条
- 模板预置/未启用：0 条

## 对外试用建议

1. 给客户试用时，优先使用默认启用规则演示目录完整性、命名、数据入口、字段结构、坐标系统、常见几何和拓扑问题。
2. 未启用规则建议包装为“行业模板可配置项”，避免承诺默认模板已经完整覆盖所有地方标准。
3. 正式项目应先根据客户规范复制模板并调整必备目录、必备图层、字段、枚举、坐标和空间关系参数。
4. 报告中的规则清单应与本文件同步交付，便于客户判断当前版本覆盖范围。
